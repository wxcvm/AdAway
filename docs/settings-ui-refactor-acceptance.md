# Compose 设置页七分类重构验收

状态：本文件与 `ui/settings-seven-sections-20261017` 同一开发分支，**尚需真机交互和视觉检查**。

## 改动范围

重构前：单个约 2,824 行的 `SettingsScreen.kt` 同时组合 20 个区域，物理顺序混乱；Web/端口、内容规则、证书、启动选项甚至位于同一大卡片内。

重构后：顶端横向滚动分类标签；仅渲染当前所选分类的控件列表；滚动位置随分类切换复位，当前分类由 `rememberSaveable` 保存。每个分类有独立标题、用途说明，统一调用 `SettingsCategoryNavigation` 与 `SettingsCategoryIntroduction`。**原有偏好键与网络设置默认值不变**。

| 分类 | 原有控件及测试重点 |
|---|---|
| 1 拦截与重定向 | 隔离 TUN 授权、停止、Echo/UDP/DNS；拦截方式切换；AdGuard 复制/关闭提示；自定义重定向；应用放行名单 |
| 2 Web 服务器与端口 | 本地/局域网监听、HTTP/HTTPS 端口及轻量模式 |
| 3 证书与 HTTPS | 证书四态、信任、导出、证书固定处理；证书操作后必须能刷新状态 |
| 4 内容与规则 | 占位响应、去重、重试护栏、决策缓存、按域熔断、响应覆盖 |
| 5 统计与图表 | 图表偏好、范围、WebSocket 实时推送 |
| 6 应用、外观与后台 | App 监控、开机启动、主题切换及相关状态 |
| 7 数据与关于 | 统计重置、备份/恢复、调试日志、IPv6/更新、版本信息、隐藏开发者选项 |

## 代码和 CI 验收

- [ ] `SettingsCategoryNavigation.kt` 和 `SettingsScreen.kt` 可通过 `:app:assembleDebug` 编译。
- [ ] `:app:testDebugUnitTest` 通过；七个分类的标题、描述在英文与简体中文中都存在。
- [ ] UI 元素数量守恒：相较之前，`Switch(`、`FilterChip(`、`OutlinedButton(`、`rememberLauncherForActivityResult(` 等主要控件调用数不减少；旧偏好键不更名。
- [ ] 真机用中文和英文分别检查七类：标题不遮挡，横向标签可滚动，长文案正常折行、触摸目标可点、系统字号放大后没有文本裁剪。
- [ ] 切换分类、旋转屏幕、主题改变及返回页面后分类状态合理；数据、规则和证书操作不串到另一类页面。
- [ ] TUN 测试必须仍显式授权、路由只包含隔离地址；切换分类不自动启用或停用任何后台服务。
- [ ] AdGuard Home 手动指引明确 DNS IP 不含端口、跨设备不能用 127.0.0.1、HTTPS 必须另行验证。
- [ ] 发布新预览前继续验证 APK 与生产 APK 使用**同一签名证书**；预览包名独立，不能覆盖正式包。
