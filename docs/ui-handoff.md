## 3. 每一项都要能回答五个问题（五段模板）

**名称 → 作用 → 当前状态 → 控件 → 生效方式**

- **名称**：用户看得懂的中文名（不是键名）；
- **作用**：一句话说清打开/关闭后发生什么；
- **当前状态**：**真实状态**而不是配置值（端口冲突要写「配置值 8080 / 生效中 8081（被占用）」）；
- **控件**：开关 / 下拉 / 输入框 / 按钮；
- **生效方式**：即时 / 重载后 / 重启后 / 需重新同步 —— **必须写明**。

### 3.1 取键规则（重要，避免"引用了不存在的文案"）

- **名称列**引该分区的 `*_title`；**没有** `*_title` 时用该分区最贴近的键（例如「应用监控」没有 title，只有 `app_monitor` / `app_allow*` / `app_sub`）；
- **作用列**引该分区的 `*_hint`；
- 引用的键必须**真实存在于** `app/src/main/res/values-zh/strings_compose.xml`，且**键名要含该分区的概念词**
  （例如可见型占位要引含 `image` 的键、按域覆盖要引含 `override` 的键）；
- 逐项草稿（已按此规则核对）见 `docs/settings-groups.md`，可直接抄。

### 3.2 文案规则

- 所有新文案进 `strings_compose.xml`（中文）与 `values-zh/strings_compose.xml`（英文）——**两份都要**；
- 不得出现「DNS 已指向即完成」这类说法（项目里有一条单测固定这条规则）；
- 涉及证书时要写明：用户库**多数 App 默认不信任**，系统级需要写 `/system` 或 APEX/apexdata；
- 涉及固定证书的应用时，**只能**说「（仅拒绝）」这类如实表述，**不得**说成拦截成功。

## 4. AdGuard 协同向导（插槽 `[E-WIZARD-SLOT]`）

**逻辑三层已完成并有 CI 证据，界面只差接线**：

| 层 | 类 | 做什么 |
|---|---|---|
| 状态机 / 三坑 | `AdGuardCoexistence` | 五态判定（standalone / adguard_coexist / other_vpn / unknown / degraded），unknown 必须让用户选 |
| 改动计划 | `AdGuardHomeCustomIp` | 只认已知格式；保存原文以支持字节级回滚；**不写文件** |
| 文件层 | `AdGuardHomeConfigFile` | 备份 → 原子写（tmp+rename）→ 写后校验 → 失败回滚；格式不认则**一字不动** |
| 实测判定 | `AdGuardHomeVerification` | DNS / 连接 / issuer 三步；**DNS 已指向但 issuer 仍是公网 CA ⇒ 判未过滤并回滚** |

界面需要做的：**展示将改什么 → 复制配置值 → 一键应用 → 实测 → 失败一键回滚**。

三个必须显式写出的坑（文案里要能看到）：

1. DNS 不带端口，服务需监听 80/443；
2. `127.0.0.1` 指的是**客户端自己**，不是服务器；
3. **DNS 已指向 ≠ HTTPS 已过滤**。

## 5. 验收清单（逐条自查）

1. 7 组顺序与上表一致；**每个现有分区都能在某一组里找到**（一个都不能丢）；
2. 每项都补齐五段模板，「生效方式」**无一遗漏**；
3. 状态行显示**真实状态**（端口冲突显示来源；证书显示四态之一；模式切换显示「配置值 / 生效中 / 成功 / 失败(原因)」）；
4. 文案全走双语资源，中英各一份；
5. 新功能一律**默认关闭**；不改既有默认行为；
6. 无障碍：开关要有可读出的名称（例如第二个开关要说明「在统计中显示」）；
7. 本地验证：`./gradlew test` 通过；CI 三条守卫（Config key contract guard / Stats field contract guard / Doc cross-reference guard）保持绿；
8. 改完后**同批升版本**（Android 由 master 推送自动出 Release；**不得**抢占 latest）。

## 6. 红线（违反任何一条都不算完成）

- 不引入 VPN/TUN（Android 保持 Root + iptables 重定向）；
- 不改默认行为、不把新功能默认打开；
- 不谎报成功（证书固定应用即使系统级生效也会失败，只能说「仅拒绝」）；
- 不手写用户设备的启动脚本；
- **不 force-push**，不碰别人的分支与 `progress-*` 预览发布；
- 不动 `docs/windows-core-contract.md` 的契约语义（那是另一个仓库的接口）。
