# 响应一致性与双栈占位图回归

旧 cache_reuse 路径只存类型标签，命中后固定回空 204，没有缓存或重放原响应。相同图片请求在短时间内会从图片 200 变成空 204，且键只有 uid／域，能波及不同 URI。现在删除该路径和上一请求状态，旧配置 true 忽略并记录警告；兼容 cache_hits 字段为 0。应用不再提供此开关，也不会从旧偏好导出 true。

独立请求去重、重试护栏、熔断仍遵守用户选项，可能主动返回空 204；不能据此承诺任意相同 URL 的应答永远一致。合法 ETag 重验证也可能返回 304，这与占位图失效不同。多个占位图素材在不同连接上被选中，也可能使图片正文不同。

tools/response-policy-fixture.py 从生产源码提取实际配置读取、分类及图片应答，使用真实 Mongoose IPv4／IPv6 私有回环监听与 HTTP 客户端。素材为现有 img_01.webp：512×768，109828 字节，SHA-256 bea27c9599dd85c22aa4fd94a08441015d74bb6f80e2ccfb0ca307dc02223976。

冻结基线相同 URI／请求头在两族均出现 200、204；修复后旧键 true 时两次均为 200，完整 body、MIME 和 SHA-256 与素材相符。还覆盖跨 URI 图片／JS／CSS、无扩展名图片、真实 ETag 304、独立去重和显式关闭图片响应。

夹具中的 UID 归属、统计 bookkeeping 和关闭的域覆盖规则是受控适配；配置、分类、快速应答与 mg_http_serve_file 来自生产源码。它不能代替 Android 进程、Root、AdGuard 或用户手机验收，也没有证明 IPv6 独有缺陷。未扩大资源限额，未改变默认素材，未新增生产依赖。
