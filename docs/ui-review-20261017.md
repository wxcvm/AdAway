# Cross-screen UI modernization — 2026-10-17

This UI branch intentionally avoids the in-flight settings navigation PR #62. Scope: overview, rules and query logs; Windows sidebar work lives in AdAway-Windows PR #12.

## Design intent
- Overview: one actionable Web Server surface rather than duplicate status cards; asynchronous root control with progress and fresh observed state.
- Rules: discard stale asynchronous search responses; show a loading indicator for large lists.
- Query logs: host-first visual hierarchy, accessible horizontally scrolling filters on narrow screens, visible loaded count and dividers; export can be used when only older records match the current filter.

## Required verification before merge
- Android Gradle compile of Compose Kotlin files and JVM tests.
- Rotation, split screen and increased font scaling at 1.3–2.0x.
- Root service start/stop failures, repeated taps and process termination.
- Rapid rule search across tabs and queries; verify only the latest result is shown.
- Query log export when recent page is empty but older loaded history matches.
- Coordinate with settings PR #62 before merge to prevent overlapping visual styles.
