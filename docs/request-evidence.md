# Web 请求证据与全部保留历史查询

本能力只覆盖 AdAway Web 服务实际观察到的请求，不代表整机 DNS 或 AdGuard 命中记录。服务器排队本地状态不证明客户端收到、浏览器成功渲染、上游完成或 QUIC 可用。

## v1 管理接口

GET /internal-qlog?filterVersion=1&offset=0&limit=300；可选 action(0..3)、family(0/4/6)、type(-1..65534)、uid(-1..INT_MAX)、q。缺失数字表示全部；-1表示未知UID/类别。q按URL表单编码，最多191UTF8字节；拒绝无效UTF8、控制字符、NUL、错误转义、重复参数和溢出，不截断。q匹配域名、已记录路径、十进制HTTP状态；ASCII忽略大小写，其他UTF8字节精确比较，不改IDN/规则归一化。

返回 filterVersion=1、queryKey(64位小写SHA256)、retainedTotal、原有分页字段及带sequence字符串的条目。total/offset/nextOffset为匹配记录数，不是原始环下标。首次不带游标且offset=0；后续带相同generation、anchor、queryKey及筛选条件。条件摘要规范为无末尾换行的 `qlog-filter-v1\naction=<*或整数>\nfamily=<*或整数>\ntype=<*或整数>\nuid=<*或整数>\nq=<ASCII小写的原查询>`。摘要不是认证材料。

筛选/版本非法400 invalid_filter；分页游标结构非法400 invalid_page；条件摘要不符400 query_mismatch；清除、重启、覆盖或无效偏移409 cursor_expired。旧客户端不请求v1时保留原语义；新版客户端检测不到v1必须提示升级服务，不退回当前页筛选。

sequence为原始观察序号十进制字符串，和generation共同标识当前运行内记录。同秒/同域名的请求不合并。重启后的历史赋予新运行编号，序号不作为跨重启持久身份。过滤后的偏移不能代替序号。旧数据缺失路径、状态、地址族时保留未知，不用当前规则重推历史。

## 界面与导出

Android条件编辑300毫秒延迟，取消旧请求并重建游标；筛选暂停实时滚动。失败保留上次显示并说明属于旧条件；过长搜索明确报错。全历史导出按固定generation/anchor/queryKey逐页完成后才生成可分享文件，展示进度/取消；失败、过期或取消不产生貌似完整的文件。只导出已记录路径，不保存查询参数/片段。

保留原资源边界：Android内存10000/Windows4096条、持久4096条、摘要400条、页面49152字节；管理筛选单次最多扫描保留历史，正常HTTP处理不扫描历史。原QLOG/QLG2/QLG3分阶段校验、失败保留和原子保存不变，不新增磁盘编号格式。

## 响应与统计

Web请求计数与已识别应用计数在转发/本地放行提前返回前记录一次。可见元素占位只在通用图片回复路径计一次，避免其他+图片重复。OPTIONS预检和本地门户回复记录本地处理动作，不把它们计为拦截。内部轮询/诊断回执不制造请求量。类别计数代表策略动作而非渲染成功；图片不存在404与条件缓存304必须记录真实排队状态。未知应用不虚构UID归属。

累计计数继续保留，时间图来自观测桶；有限历史不推导累计。已有历史异常数据不清空修饰；新请求用差量对照验证。TLS失败不直接归因为证书固定，高请求速率不证明重试循环。界面采用服务器实测窗口速率，旧服务器缺字段时才回退明确的平均值。Web统计不称为整机DNS拦截数。

本机/模拟器回归不能替代Android17/Root/AdGuard用户环境或RISC-V运行。真实设备只按当前授权只读取证，安装由用户自行完成，证书/系统网络/AdGuard不改动。
